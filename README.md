# Книга відгуків

Проєкт реалізує веб-додаток на базі Jakarta EE для додавання та перегляду відгуків. Для обробки HTTP-запитів використовуються сервлети, а для збереження даних — вбудована база даних H2.

## Технологічний стек

* **JDK:** 21
* **Maven:** 3.9.16

## Команда запуску

Для збірки та запуску вбудованого сервера Jetty виконайте в кореневій директорії проєкту наступну команду:

```bash
mvn clean compile
mvn jetty:run
```

Після успішного запуску додаток буде доступний у браузері за адресою: `http://localhost:8080/`

## База даних

* **СУБД:** H2 (працює в локальному файловому режимі).
* **URL підключення:** `jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`
* **Шлях до файлу БД:** `./data/guest.mv.db` (створюється автоматично в корені проєкту при першому запуску).

## Список ендпоїнтів

### Сторінки

* **`GET /`**

  * Головна HTML-сторінка. Містить форму для відправки відгуку (ім'я та текст) і динамічний список залишених коментарів.

### API (Сервлети)

* **`GET /comments`**

  * Повертає JSON-список усіх збережених відгуків. Сортування: від найновіших до найстаріших (останні зверху).
  * Успішний статус: `200 OK`.

* **`POST /comments`**

  * Додає новий запис у базу даних. Тіло відповіді відсутнє.
  * **Параметри (Form Data):**

    * `author` (обов'язково, макс. 64 символи)
    * `text` (обов'язково, макс. 1000 символів)
  * Успішний статус: `204 No Content`.
  * Помилка валідації: `400 Bad Request`.
  * Помилка бази даних: `500 Internal Server Error`.
